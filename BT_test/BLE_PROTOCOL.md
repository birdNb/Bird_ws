# Bird BLE 通讯指令规范

> 写入 **FFE1** 的 UTF-8 纯文本，**不含换行**。相同摇杆帧板端会去重。

UUID：`FFE0` 服务 / `FFE1` 写入 / `FFE2` 通知（ACK）

---

## 一、纯文本指令

### 1. 摇杆平移 / 自转

| 字段 | 范围 | 说明 |
|------|------|------|
| X | -1.00 ~ 1.00 | 左摇杆横向 → 平移 |
| Y | -1.00 ~ 1.00 | 左摇杆纵向 → 平移 |
| Z | -1.00 ~ 1.00 | 右摇杆横向 → 自转 |

**格式**（固定顺序，两位小数）：

```text
X:{x},Y:{y},Z:{z}
```

示例：`X:0.85,Y:-0.60,Z:0.00`

| 参数 | 值 |
|------|-----|
| 发送间隔 | **50 ms** |
| writeType | `writeNoResponse` |
| 死区 | **10**（UI 内部 -100~100 刻度，\|v\|<10 发 0.00） |
| 板端死区 | \|v\| < 0.10 归零 |
| 摇杆日志 | 默认**不打印**（防刷屏） |
| ACK | **无** |

**轴映射**：左摇杆 UI 的 X/Y → 协议 X/Y；右摇杆仅 axisX → Z。

---

### 2. 运行模式

进入遥控页默认发送 `M_default`；顶栏切换时发送对应指令。

| 界面名称 | 文本指令 | 说明 |
|----------|----------|------|
| 默认 | `M_default` | 进入遥控后的初始模式 |
| 初始化 | `M_init` | 初始化模式 |
| 保护 | `M_protect` | 保护模式 |
| 调零 | `M_resetzero` | 调零模式 |
| 示教 | `M_tech` | 示教模式 |

- writeType：默认 write（有响应）
- ACK：`ACK:M_default` 等（FFE2）

---

### 3. 手柄组合键（预选动作）

格式：`键名+键名+…`，**大小写与下表一致**。

| 功能 | 文本指令 | 触发方式 |
|------|----------|----------|
| 起立 | `LT+RT+start` | 底部预选，长按 1 秒 |
| 蹲下 | `LT+RT+RB` | 底部预选，长按 1 秒 |
| 挥双手 | `RT+A` | 底部预选，长按 1 秒 |
| 步态启停 | `LT+RT+LB` | 底栏绿色按钮，单击切换 |
| 卸力 | `LT+RT+B` | 顶栏按钮；每次单击下发 |

- ACK：`ACK:LT+RT+start` 等（原样键名）

---

## 二、连接流程（小程序）

```
扫描 FFE0 → createBLEConnection → 延时 → setBLEMTU(247)
→ getServices/Characteristics → 订阅 FFE2
→ write FFE1 "M_default"
→ 50ms 周期摇杆 writeNoResponse
```

## 三、板端 ROS 映射

| 指令 | ROS |
|------|-----|
| 摇杆 | `/cmd_vel` |
| 模式 / 动作 | `/joy_msg`（复用手柄链路） |

断连：零速 + 清空队列。
