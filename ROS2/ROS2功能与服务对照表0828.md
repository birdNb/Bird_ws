# ROS2 功能与服务对照表

本机：**PiPlus Orin H1W（有腰）** · 工作空间 `~/hightorque_workspace` · 动作库 `~/action_library`  
Launch：`bfm_real.launch.py` 且 `enable_gamepad_commands:=true` 时，下表手柄列才生效。

---

## 0. 标准使用流程（纯手柄，严格按功能表）

> **禁止用命令行启动站立/策略**；自启脚本只拉起 ROS2 栈，不代替手柄操作。

| 步骤 | 上层状态 | 手柄操作 | 功能表 |
|------|----------|----------|--------|
| ① | `init` | **LT + RT + Start**（先 LT+RT，再点 Start） | §1 站立 |
| ② | `standby` | **LT + RT + LB** | §1 启停策略 |
| ③ | `running` | 左摇杆 | §6 行走 |
| ④ | `running` | **RT + A/B/R/Y**（勿按 LT） | §5 动作 |
| ⑤ | `standby`/`running` | **只按 LT** + A / 左摇杆 / 右摇杆 | §3 切 bfm/amp |
| ⑥ | 底层 FSM | HOME=default；**LT+RT+A**=确认；**LT+RT+B**=保护 | §2 |

**你之前的现象 = LT 未被识别时的误触发：**

| 你以为在按 | LT 失效时实际变成 | 修复后 |
|------------|-------------------|--------|
| LT+RT+A | RT+A → 挥双手 | LT+RT+A → **FSM 确认** |
| LT+RT+B | RT+B → 握手 | LT+RT+B → **FSM 保护** |
| LT+A 切 BFM | 无效 | LT+A → **bfm 策略** |

已修复 `joy_mapper_node`：**北通 A2P3** 专用布局（Start=btn11，LT/RT=轴5/4，扳机松开=1.0）。改完后需 **colcon build 并重启栈**。

> HOME = FSM 进 default，**不会自动站立**；上层仍需 ① 站立 → ② 启策略。

---

> **手柄两条独立链路（重要）**  
> - **运动方向**：`/joy` → `joy_mapper_node` → `/cmd_vel`（不经过功能键仲裁，**running 后**才有效）  
> - **站立/切策略/动作**：`/joy` → `joy_mapper_node` → `/hightorque_joy` → `input_arbiter_walk` → 服务调用  
> 摇杆能走但按键无效，通常是第二条链路被门控/武装条件挡住，或仍停在 `init` 状态。

> **按键生效前提**  
> 1. 先**全部松键 1～2 秒**，等日志 `command gate armed`  
> 2. **单按 LT** 切 bfm/amp（不要同时按 RT）  
> 3. **LT+RT+Start** 站立：先按住 LT+RT，再**点按** Start  
> 4. 门控未 ready 时（旧配置）除站立/FSM 外全部无效；本机已改为 `gamepad_require_startup_guard_ready:=false`

**每个终端调用服务前先：**

```bash
source /opt/ros/foxy/setup.bash
source ~/hightorque_workspace/install/setup.bash
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp
export CYCLONEDDS_URI=file:///home/nvidia/cyclonedds.xml
```

> 说明：带 ⚠️ 的 waypoint 为无腰机型开发，**有腰设备稳定性差，不建议使用**。  
> 带 ❌ 的策略在本机 Jetson 上不可用（`catalog.yaml` 未声明 `jetson` 平台）。

## 1. 上层状态（行为树 default_bt）

| 功能 | 服务名称 | 服务类型 | 手柄指令 | 服务调用示例 |
|------|----------|----------|----------|--------------|
| 站立 | `/hightorque_controller/change_state` | `hightorque_msgs/srv/ChangeState` | LT + RT + Start | `{states: ['standing']}` |
| 坐下 | `/hightorque_controller/change_state` | `hightorque_msgs/srv/ChangeState` | LT + RT + RB（仅 standby） | `{states: ['siting']}` |
| 启停策略（toggle） | `/hightorque_controller/change_state` | `hightorque_msgs/srv/ChangeState` | LT + RT + LB | `{states: ['toggle_policy']}` |
| 启动策略 | `/hightorque_controller/start_policy` | `hightorque_msgs/srv/Common` | — | `{enable: true, str: ''}` |
| 停止策略 | `/hightorque_controller/stop_policy` | `hightorque_msgs/srv/Common` | — | `{enable: false, str: ''}` |

**状态顺序：** `init` → 站立 → `standby` → 启动策略 → `running`；停止策略回到 `standby`。

## 2. 底层 FSM（电机层模式）

服务：`/hightorque_controller/change_fsm_state` · 类型：`hightorque_msgs/srv/ChangeState`

| 功能 | 手柄指令 | 服务 `states` 参数 |
|------|----------|-------------------|
| 进入 DEFAULT 控制模式 | HOME（center） | `['default']` |
| FSM 候选下一项 | LT + RT + 十字右 | `['next']` |
| FSM 候选上一项 | LT + RT + 十字左 | `['prev']` |
| 确认候选 FSM | LT + RT + A | `['confirm']` |
| 进入保护模式 PROTECT | LT + RT + B（×1） | `['protect']` |
| 退出保护 / 回 INIT | LT + RT + B（保护态下） | `['protect']` 或 HOME |
| 强制回 INIT | — | `['init']` |

> FSM 与上层站立无关；`default` 只切底层模式，**不会自动站起来**。

## 6. 基础运动

无专用服务，通过 **话题** `/cmd_vel`（`geometry_msgs/msg/Twist`）控制。  
手柄由 `joy_mapper_node` 映射（与 yaml 无关），需 `current_state=running`。

| 功能 | 服务/话题 | 手柄指令 |
|------|-----------|----------|
| 前进 / 后退 | 话题 `/cmd_vel` · `linear.x` | 左摇杆 前 / 后 |
| 左移 / 右移 | 话题 `/cmd_vel` · `linear.y` | 左摇杆 左 / 右 |
| 斜向八向 | 话题 `/cmd_vel` | 左摇杆 对角 |
| 原地左转 / 右转 | 话题 `/cmd_vel` · `angular.z` | 右摇杆 左 / 右 |
| 行进中转向 | 话题 `/cmd_vel` | 左摇杆 + 右摇杆 |
| 2 倍速 | 话题 `/cmd_vel`（缩放 ×2） | **仅 RB** 按住（LT/RT 未按） |
| 停止 | 话题 `/cmd_vel` 全 0 | 摇杆回中 |

**服务式发速示例：**

```bash
ros2 topic pub /cmd_vel geometry_msgs/msg/Twist \
  "{linear: {x: 0.2, y: 0.0, z: 0.0}, angular: {x: 0.0, y: 0.0, z: 0.0}}"
```

BFM 方向运动 PKL：`~/hightorque_workspace/install/hightorque_bfm_motion_source/share/hightorque_bfm_motion_source/motions/piplus_h1w/`

## 10. 通用服务调用模板

```bash
# 切换策略
ros2 service call /hightorque_controller/switch_policy \
  hightorque_msgs/srv/SwitchPolicy "{policy_name: 'bfm'}"

# 执行 waypoint
ros2 service call /hightorque_controller/execute_waypoint \
  hightorque_msgs/srv/ExecuteWaypoint "{action_name: 'cheer'}"

# 切换 FSM
ros2 service call /hightorque_controller/change_fsm_state \
  hightorque_msgs/srv/ChangeState "{states: ['default']}"
```
